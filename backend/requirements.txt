# Pinned to the versions this image was last built and import-tested against.
# When bumping a pin, re-test the app (esp. bcrypt/pydantic/SQLAlchemy, which
# this code targets the modern major-version API of) before committing.
#
# yt-dlp is deliberately NOT pinned here: YouTube breaks it often enough that
# pinning it would mean the app silently going stale between image releases.
# deploy/entrypoint.sh runs `pip install -U "yt-dlp[default,deno]"` at container
# startup so a restart alone can pick up an upstream fix, no rebuild required.
#
# The extras matter: YouTube extraction now needs a JavaScript runtime plus
# yt-dlp's challenge-solver scripts (github.com/yt-dlp/yt-dlp/wiki/EJS).
# "default" pulls the yt-dlp-ejs solver at the exact version this yt-dlp
# wants, "deno" a deno binary from PyPI -- so the three always move together.
# Without them the `web` client is skipped: some formats go missing and
# age-restricted videos fail even with valid account cookies.
